# Простор

Трекер задач и проектов: проекты с настраиваемыми полями, задачи с комментариями, вложениями, связями и тегами, свой язык запросов, доски со спринтами и бэклогом, обновления в реальном времени, уведомления с почтой, тонкая настройка прав.

> **Статус: построено ядро (P1).** Команда может вести ежедневную работу: проекты, задачи, поиск, доски, права, уведомления и область администрирования.

## Дорожная карта

Вехи, без частностей:

| Веха | Суть | Статус |
| --- | --- | --- |
| P0 Каркас | Скелет проекта, вход, инструмент замеров | готово |
| P1 Ядро | Ежедневная работа команды: проекты, задачи, поиск, доски, права, уведомления | готово |
| P2 Командная работа | Скорость большой команды: команды, автоматизация, массовые операции | в работе |
| P3 Планирование и аналитика | Отчёты, дашборды, диаграммы Ганта, учёт времени | в плане |
| P4 Экосистема | Хелпдеск, интеграции, импорт, корпоративный вход | в плане |

## Стек

| Часть | Выбор | Почему |
| --- | --- | --- |
| Сервер | Rust: tokio, axum, sqlx | Быстрый машинный код без пауз сборщика мусора, мало памяти на соединение; строгий компилятор ловит ошибки до запуска |
| База данных | PostgreSQL | Одна база для данных, фоновых задач и рассылки событий; полнотекстовый поиск |
| Интерфейс | Svelte 5, SvelteKit, TypeScript | Маленький размер страниц; при изменении одной карточки на доске перерисовывается только она. Mobile first |
| Реальное время | WebSocket | Одно соединение на вкладку: доски, задачи и списки обновляются сами, без перезагрузки |
| Поставка | Один исполняемый файл + PostgreSQL | Простая установка и обновление: готовый образ `ghcr.io/hiraise/prostor`, Docker Compose |

## Цели по скорости

Замеряем на тестовой базе в 100 тысяч задач (стресс-проверка — 1 млн):

- открыть задачу — до 30 мс на сервере;
- страница списка задач — до 50 мс;
- доска на 500 карточек — до 80 мс, прокрутка и перетаскивание без рывков;
- изменение видно у коллег — до 150 мс.

| Папка или файл | Что внутри |

## Запуск для разработки

Нужны macOS или Linux, [Docker](https://www.docker.com/), [rustup](https://rustup.rs) и Node 24 (через nvm: `nvm install` в папке проекта). Всё ли установлено, покажет `make doctor`.

Первый раз установить зависимости интерфейса и браузер для его тестов, затем запустить в режиме разработки (база, почтовый перехватчик, сервер и интерфейс с автообновлением):

```bash
make setup
make dev
```

Откройте <http://localhost:5173>. При первом запуске откроется мастер настройки: он попросит код установки — его сервер пишет в свой журнал (строка «Prostor is not set up yet … setup code …»). После настройки вы войдёте как администратор. Письма, которые отправит Простор, видны на <http://127.0.0.1:8025>.

Для разработчиков: описание API — <http://localhost:5173/api/v1/openapi.json>, проверки для балансировщика — `/api/v1/health/live` и `/api/v1/health/ready`.

## Развёртывание

Один Docker-образ с сервером и интерфейсом внутри плюс PostgreSQL:

```bash
docker buildx build --platform linux/amd64 -f deploy/Dockerfile -t prostor:latest --load .
```

Затем `deploy/compose.server.yaml` — подробно, включая обновление и резервные копии, — в [deploy/README.server.md](deploy/README.server.md). Установка, вход и восстановление доступа администратора — в [docs/guide/admin.md](docs/guide/admin.md).
